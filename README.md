# proof-dashboard

A single static HTML page that reads mahirhir's merged and open pull requests live from the
GitHub REST API and renders them as a dashboard — no build step, no backend, nothing hand-typed.

It exists as third-party proof: every entry links to the real PR page on the upstream project
(vite, ant-design, raylib, nestjs, gin, medusa, and others), so the claim is checkable at the
source rather than taken on trust. Served as-is via GitHub Pages at
`https://mahirhir.github.io/proof-dashboard/`.
